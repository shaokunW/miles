# Changelog

## 2.0.0 — 2026-09-20

- Adds experience modeling as a core responsibility: goal, qualities, concept, function, properties/rules, and validation.
- Makes project conditions useful through an explicit condition/mechanism/consequence/implication trace.
- Requires Miles to propose understandable interpretations for developers with limited design experience.
- Connects camera, orientation, visual hierarchy, color, decoration, functional objects, UI, and pacing to their responsibilities.
- Separates implementation acceptance from player-experience validation in the core, briefs, handoffs, tests, and decision history.
- Preserves accepted experience models inside existing Project Context while keeping predicted effects and empirical support distinct.
- Adds a handoff guide and template, full craft-shop and workstation examples, and a contrasting quiet-horror model.
- Updates discovery to synthesize intent before asking for consequential choices; retains lightweight local work.
- Adds migration instructions, new behavioral scenarios, and additional package-integrity tests.
- Reopens the packaging references, Fullerton overview, and XAG 103; adds Norman's Emotional Design overview and Design Council's Double Diamond. Other source access notes are carried from V1.1.

## 1.1.0 — 2026-09-20

- Added a first-engagement Project Discovery mode before substantive feature recommendations.
- Required a visible, connected Project Understanding and a task-relative readiness check.
- Limited decision-local discovery shortcuts to work grounded in a coherent game model.
- Distinguished consequential foundational gaps from reversible implementation details.
- Added explicit dependency review when later requests affect earlier recommendations.
- Updated onboarding guidance, project/brief templates, response rules, and integration text.
- Added an original project-discovery example and four behavioral regression fixtures.
- Preserved the existing memory authority, write-safety rules, reference library, and classic cases.
- Behavioral fixtures remain unexecuted against a live host/model in this release.

## 1.0.0 — 2026-09-20

- Added the Miles senior game experience designer skill and optional Codex UI metadata.
- Separated durable project context, current design context, and scoped decision history.
- Added player-experience, onboarding, interaction, progression, validation, and memory guides.
- Added foundational reference cards, a source registry, six classic cases, and three original worked examples.
- Added blank project templates, an explicit initializer, structural checks, unit tests, and behavioral evaluation scenarios.
